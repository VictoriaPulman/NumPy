# 📊 Практический кейс: Анализ данных с помощью NumPy

Учебный проект, посвященный изучению базовых возможностей библиотеки NumPy, манипуляциям с массивами и первичному анализу данных.

## 📂 Структура проекта

В репозитории содержатся следующие файлы:

* 📄 [todo.md](./todo.md) — интерактивный чек-лист по развертыванию, настройке виртуального окружения Windows и интеграции проекта с Git.
* 📓 [numpy_practice.ipynb](./numpy_practice.ipynb) — основной рабочий блокнот (Jupyter Notebook), в котором ведется анализ данных, пишутся функции NumPy и строятся тестовые графики.
* 📊 [data.txt](.data/data.txt) — исходный текстовый файл с данными для проведения практического анализа.
* ⚙️ [.gitignore](./.gitignore) — технический файл, который скрывает от Git тяжелую системную папку виртуального окружения (`.venv`).
* 📄 [README.md](./README.md) — собственно я, тот файл, что ты сейчас читаешь.
