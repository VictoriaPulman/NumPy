# 📊 Практический кейс: Анализ данных с помощью NumPy

Учебный проект, посвященный изучению базовых возможностей библиотеки NumPy, манипуляциям с массивами и первичному анализу данных.

## 📂 Структура проекта

В репозитории содержатся следующие файлы:

* 📄 [todo.md](./todo.md) — интерактивный чек-лист по развертыванию, настройке виртуального окружения Windows и интеграции проекта с Git.
* 📓 [numpy_practice.ipynb](./numpy_practice.ipynb) — основной рабочий блокнот (Jupyter Notebook), в котором ведется анализ данных, пишутся функции NumPy и строятся тестовые графики.
* 📊 [data.csv](data/data.csv) — исходный текстовый файл с данными для проведения практического анализа.
* ⚙️ [.gitignore](./.gitignore) — технический файл, который скрывает от Git тяжелую системную папку виртуального окружения (`.venv`).
* 📄 [README.md](./README.md) — собственно я, тот файл, что ты сейчас читаешь.

---
### 🛠 Ключевые этапы анализа:

* **Импорт данных в матрицу**
  Реализована прямая загрузка табличных данных из CSV-файла в двумерный числовой массив NumPy (с помощью `np.genfromtxt`), минуя использование сторонних библиотек анализа данных.

* **Векторизованные вычисления на срезах**
  Выполнены матричные операции над отдельными признаками (столбцами расстояния и времени) для создания нового синтетического признака скорости (с конвертацией секунд в часы). На основе полученного вектора рассчитано общее среднее значение скорости.

* **Сложная фильтрация и булево индексирование**
  Применены логические фильтры для выборки строк по точным условиям: выделено подмножество поездок за конкретный месяц и подсчитано количество аномальных записей с чаевыми выше \$50. Отработана продвинутая фильтрация выбросов с помощью комбинации условий `np.where`, проверки на пропуски `np.isnan` и оператора логического отрицания `~`.

* **Статистический анализ матриц**
  Рассчитана полная матрица ковариации (15х15) для оценки взаимосвязей между всеми переменными датасета с использованием транспонирования и изменения ориентации строк. Дополнительно выделена уменьшенная матрица ковариации для точечного анализа взаимосвязи конкретных метрик (расстояния, времени, стоимости и чаевых).
